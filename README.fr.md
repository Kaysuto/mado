# Mado

> Le poste de travail tout-en-un des développeurs, avec le modèle d'IA de leur choix.

**Mado** (窓, « fenêtre » en japonais) réunit mails, agenda, tâches, demandes de fusion, tickets, agents de code et actus dans une seule application de bureau, qui garde les données sur votre machine. Le modèle est au choix : un abonnement déjà payé, une clé API, une offre gratuite ou un modèle qui tourne sur votre ordinateur.

En cours de construction : la première version utilisable n'est pas encore sortie.
